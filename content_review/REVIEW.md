# 内容审查记录

## 审查方法

逐批编写并回读核心讲解、阅读事实、题目选项及解析，复核翻译中的对象、否定、时间、范围与确定程度。程序另外检查完整性、ID、答案范围和完全重复。程序通过仅代表这些形式条件满足。

## 模块审查重点

| 日程 | 医学与语言审查 |
| --- | --- |
| 1–21 | 词根/结合形式分离，诊断单复数，主观症状与客观体征，后缀不直接给出病因，not all与cannot exclude的范围 |
| 22–31 | 动静脉按流向命名；肌钙蛋白升高表达心肌损伤；保留射血分数不独立排除心衰；抗凝与抗血小板区分 |
| 32–38 | 气促/呼吸频率/血氧分层；影像和痰色不能确定病原体；通气与氧合区分；睡眠筛查与确诊区分 |
| 39–49 | 吞咽困难与吞咽痛区分；呕血与咯血区分；肝酶损伤线索与合成功能分离；既往静脉曲张不证明本次出血源 |
| 50–56 | 输尿管与尿道；尿频与尿量；急慢性需时间证据；蛋白尿与滤过率互补；透析不由单一肌酐自动决定 |

## 审查后修正

- Day 34、40、45、67、72、86中若干过短解释补充为明确的事实依据。
- Day 87与Day 37的通用问句相同，改为明确针对偶然影像异常的问题，避免脱离语境的重复题干。
- anaphylaxis统一为严重全身过敏反应，避免暗示每例均已发生休克。
- hemiparesis统一为偏轻瘫或单侧肢体无力，避免与完全偏瘫混淆。
- 日课中的再现词汇有意用于系统内及跨系统复习，使用相同词汇ID。独立术语455个，90课共1350个词汇学习位置。

- 复习日教材回读提示统一为15–20分钟，与总时间表一致，消除常规日45＋15分钟提示的混入。

## 难度及限制

前期侧重术语、短句、信息定位；后期增加让步、定语从句、多个时间层次及医学证据边界。四套模考限时60、70、80、90分钟，均为100分。每日训练题全部提供，教材阅读和配套练习可按既定90分钟方案分次使用。

当前阅读以医学英语理解和临床推理措辞为主，多为短病例或教学场景。部分基础题的干扰项较易排除，适合作为循序训练；尚无真实学生样本用于难度、区分度或信度估计。临床短病例没有统一补造未提供的实验室值或影像。原教材逐页、小节及题号对应尚未核对正文。
