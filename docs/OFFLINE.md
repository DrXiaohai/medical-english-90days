# 离线学习

首次使用需要联网。打开在线课程后，等待顶部出现“90天课程已缓存，可离线学习”，再断网使用。缓存包括全部90天课程、四套模考和界面所需资源，后续打开其他学习日也可离线。

## iPhone / iPad

在Safari打开网站，点击分享 → 添加到主屏幕。随后从主屏幕图标联网打开一次，等缓存就绪。之后可在飞行模式或没有网络时从图标进入课程。

Safari与主屏幕应用的实际存储行为由系统管理，两个入口都以顶部缓存提示为准。学习记录继续保存在当前设备和浏览器，跨设备转移可用原有JSON导出/导入。

## 更新课程

联网访问时会在后台检查新版本。完整下载并校验后，顶部显示“新版本已缓存”。结束当前学习、确认记录已保存后，关闭所有课程标签页及主屏幕窗口，再重新打开，便可使用新版。更新期间当前窗口继续使用其完整缓存版本。

下载不完整或资源版本不一致时，旧缓存保留。浏览器回收静态缓存后，联网打开页面可使用“重试缓存”重新下载。清理全部网站数据会连同学习记录一起删除，可定期导出JSON备份。

## 缓存范围

Service Worker位于本站路径的sw.js，作用域与Vite base一致。缓存仅包含构建清单中的同源静态资源，外部医学参考链接仍需联网。缓存管理与IndexedDB学习记录分开。

缓存按发布内容生成版本号，下载时验证每个资源的SHA-256。新版本准备好后等待旧窗口结束，再清理本项目旧版本缓存。其他网站路径的缓存不属于该清理范围。

## 验证

npm test包含离线生命周期测试。npm run verify:pages检查缓存清单与构建资源。scripts/offline_browser_check.cjs使用隔离浏览器资料目录，验证90课断网导航、浏览器退出后重开、作答保存、版本等待、失败更新保护及缓存修复。

可先构建，再配置PLAYWRIGHT_PATH指向已安装的Playwright模块运行该脚本。运行需要本机Chrome。

```bash
VITE_BASE_PATH=/medical-english-90days/ npm run build
node scripts/offline_browser_check.cjs
```
